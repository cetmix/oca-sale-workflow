This module extends OCA ``sale_fixed_discount`` to allow setting a
discount defined as a fixed monetary amount in the sale order currency,
rather than a percentage, on the sale order level.

.. contents::

Use Cases / Context
===================

In some business scenarios (e.g., promotional campaigns, manual
negotiation, or rounding adjustments), a salesperson needs to offer a
fixed monetary discount on the whole order rather than a percentage per
line.

Usage
=====

To use this module, you need to:

- Create a sale order and add at least one order line;
- In the **General Fixed Discount** field Enter the fixed discount
  amount in the sales order currency (e.g., ``50.00``);
- The system will proportionally distribute this amount across all order
  lines, updating the **Fixed Discount** column (``discount_fixed``) on
  each line.

**Note:** If order lines are added, updated, or removed after setting
the global fixed discount, the distribution is recalculated
automatically.
