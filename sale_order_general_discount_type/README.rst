This module extends the Sale Order form to introduce a Discount Type
selection field.

When a discount type is selected and a value entered, the corresponding
module’s existing logic handles propagation to all sale order lines
(percentage applied via standard discount field; fixed amount applied
via discount_fixed field). This module does not re-implement the
downstream propagation logic - it only controls which input is exposed.

Usage
=====

To use this module:

1. Open or create a Sale Order
2. Add Sale order lines
3. Locate the Discount Type dropdown, placed directly above the discount
   value field
4. Select Percentage:

   - The General Discount (%) field becomes visible.
   - Enter the desired percentage value.
   - The entered value is propagated to all sale order lines through
     their standard Discount (%) field.

5. Select Fixed Amount:

   - The General Fixed Discount field becomes visible; the percentage
     field is hidden.
   - Enter the desired fixed monetary amount.
   - The entered value is propagated to all sale order lines through the
     Fixed Discount field.

Note: Switching the Discount Type clears the previously entered value of
the hidden field to avoid stale data being silently applied.
