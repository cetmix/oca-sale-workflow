To use this module:

1. Open or create a Sale Order
2. Add Sale order lines
3. Locate the Discount Type dropdown, placed directly above the discount value field
4. Select Percentage:
    - The  General Discount (%)  field becomes visible.
    - Enter the desired percentage value.
    - On confirmation / applying the discount, all sale order lines receive the percentage discount in their standard  Discount (%)  field.
5. Select Fixed Amount:
    - The  General Fixed Discount  field becomes visible; the percentage field is hidden.
    - Enter the desired fixed monetary amount.
    - On confirmation / applying the discount, all sale order lines receive the fixed discount via the  Fixed Discount  field.

Note: Switching the Discount Type clears the previously entered value of the hidden field to avoid stale data being silently applied.
